# Echte Sounds und Musik (optional)

Das Spiel erzeugt alle Geräusche und die Musik selbst. Echte Aufnahmen ersetzen diese Platzhalter automatisch:

- **Effekte:** `sfx/<name>.ogg` oder mehrere Varianten `sfx/<name>_1.ogg`, `sfx/<name>_2.ogg` …
  Namen: `punch`, `crit`, `boing`, `squeak`, `buy`, `golden`, `achievement`, `bad`, `shoe_appear`, `rage`,
  `prestige`, `applause_small`, `applause_big` (Sound-Packs zusätzlich mit Präfix `retro_` bzw. `kampf_`).
- **Musik:** `music/loop.ogg` (wird in Schleife gespielt; dann ohne wachsende Instrumente).

Formate: OGG, WAV oder MP3. Bitte nur Dateien mit passender Lizenz (z. B. CC0 von kenney.nl) und die Lizenz hier dazulegen.
