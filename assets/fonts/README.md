# Schriften

- `Poppins-Medium.ttf` (Text) und `Poppins-Bold.ttf` (Überschriften, Zahlen) – SIL Open Font License 1.1, siehe `OFL.txt`.

## Eigene Comic-Schrift für Überschriften

Lege eine Schrift als **`heading.ttf`** (oder `heading.otf`) in diesen Ordner – zum Beispiel
[Bangers](https://fonts.google.com/specimen/Bangers) oder [Luckiest Guy](https://fonts.google.com/specimen/Luckiest+Guy)
(beide OFL). Das Spiel nimmt sie dann automatisch für Titel, Wumms-Zähler, Comic-Wörter und Popups.
Die Lizenzdatei der Schrift bitte mit hierher legen (z. B. `heading-OFL.txt`).
